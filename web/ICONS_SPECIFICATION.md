# StudyHub — Custom Iconography & Visual Asset Specification

> **Version:** 2.0  
> **Brand Identity:** StudyHub Academic Blue & Navy with Cyan, Gold, and Fresh Green accents  
> **Target Audience:** Ethiopian University Students (AAU, ASTU, AASTU, Jimma, Gondar, etc.)  
> **Style Philosophy:** High-clarity geometric dual-tone or 2.5D academic emblems. Clean lines (1.75px–2px stroke), 10px–14px corner radii, tinted soft-fill containers, and crisp scalable vector geometry (SVG).

## 6. Implementation Guidelines

### Dimensions & Grid
* **Badge / Inline Icons:** `16px × 16px` or `20px × 20px` (viewBox: `0 0 20 20`)
* **Card & Toolbar Icons:** `24px × 24px` (viewBox: `0 0 24 24`)
* **Category / Feature Blocks:** `48px × 48px` or `56px × 56px` (viewBox: `0 0 48 48`)
* **Empty State Illustrations:** `120px × 120px` to `240px × 240px`

### Technical Formats
* **Primary:** Inline React SVG components with `currentColor` fills and CSS variable bindings (`var(--primary)`, `var(--cyan)`, `var(--pdf-color)`).
* **Benefits:** 0 network latency, 0 layout shifts, automatic dark/light theme transitions, and zero extra bundle weight.
